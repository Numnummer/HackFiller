# ImageScope

Веб-приложение: собирает изображения с каталога каталога, анализирует их (NumPy), обрабатывает фильтрами (NumPy и PyTorch `conv2d`) и показывает «до/после».

**Источник:** <https://wallpaperscraft.com/catalog/art/1920x1080> — каталог обоев «Art», открыт без авторизации, robots.txt разрешает обход (Crawl-delay 1 с — соблюдается). Парсятся страницы `…/1920x1080`, `…/page2…page8` (≈15 превью на страницу, 120 изображений; селектор `img.wallpapers__image`). Ссылка на превью `…_300x168.jpg` заменяется на оригинал `…_1920x1080.jpg` (тот же файл, что на странице `/download/<имя>/1920x1080`), поэтому статистика считается по Full HD. Адрес задан в [app/config.py](app/config.py).

**Концепция:** «улучшение карточек каталога» + творческие стили (комикс, ретро, пиксель-арт, набросок).

## Запуск

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt      # CPU-torch: --extra-index-url https://download.pytorch.org/whl/cpu
uvicorn app.main:app --reload
```
Откройте http://127.0.0.1:8000.

**CPU / CUDA.** PyTorch-фильтры сами используют GPU, если доступна CUDA (устройство видно в `GET /health` → `torch_device`). Принудительно: `IMAGESCOPE_DEVICE=cpu` или `cuda`. Для GPU нужна CUDA-сборка torch, например `pip install torch --index-url https://download.pytorch.org/whl/cu121` (CPU-сборка `+cpu` работает только на процессоре). Тесты: `python -m pytest`.

## Цепочка
интерфейс (`static/`) → `POST /api/analyze` (FastAPI) → `parser.py` (HTML с тайм-аутом, `<img>`, относительные ссылки → абсолютные, загрузка с лимитом размера) → `processing.py` (статистика NumPy, фильтры NumPy/PyTorch) → JSON с оригиналами и результатами (data URI) → галерея «до/после».

## API
| Метод | Маршрут | Назначение |
|---|---|---|
| GET | `/health` | готовность |
| GET | `/` | интерфейс |
| GET | `/api/filters` | список фильтров и пресетов |
| POST | `/api/analyze` | `{filter, intensity 0..1, limit 1..20}` → источник, сводка, изображения со статистикой, применённые фильтры, список ошибок |

Устойчивость: тайм-ауты на страницы и картинки (10 с), лимит 3 МБ на файл, ≤20 изображений, превью ≤640 px. Недоступное или битое изображение попадает в `errors`, остальные обрабатываются.

## Статистика (NumPy)
Ширина, высота, соотношение сторон, средняя яркость, контраст (std яркости), средний цвет, доли тёмных/светлых пикселей, 16-бинная гистограмма, флаги («слишком тёмное», «низкий контраст»).

## Фильтры
Размеры эффектов (радиус размытия, толщина контуров, блок пикселизации) масштабируются от разрешения картинки, поэтому на Full HD они заметны так же, как на маленьких превью.

**NumPy (операции над массивами):** `grayscale`, `invert`, `sepia` (матрица 3×3), `posterize` (3–8 уровней), `pixelate` (блок до 4% стороны), `threshold`, `gamma` (подъём теней), `auto_contrast` (растяжение по 1–99 процентилям), `saturate` (цвета отталкиваются от серого), `vignette` (радиальная маска).
**PyTorch (`torch.nn.functional.conv2d`, тензор 1×C×H×W, depthwise):** `blur` (Гаусс, два разделимых conv2d), `sharpen` (unsharp mask: исходник + A·(исходник − размытие)), `emboss` (сглаживание + ядро emboss), `edges` (Собель, 2 ядра, линии на белом), `ink` (контуры Собеля поверх картинки).

**Пресеты:**
- `product_boost` — автоконтраст + гамма + насыщенность + резкость: ярче и чётче карточка.
- `comic` — автоконтраст + постеризация + насыщенность + чёрные контуры Собеля.
- `retro` — сепия + мягкость + тиснение + виньетка.
- `pixel_art` — крупные пиксели и ограниченная палитра.
- `sketch` — только контуры, карандашный набросок.

Интенсивность 0..1 масштабирует силу каждого шага цепочки. По клику на картинку открывается Full HD «до/после» (`GET /api/img/<token>.jpg`, хранится в памяти последних запросов).
