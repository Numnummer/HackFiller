# ImageScope

Веб-приложение: собирает изображения с каталога интернет-магазина, анализирует их (NumPy), обрабатывает фильтрами (NumPy и PyTorch `conv2d`) и показывает «до/после».

**Источник:** <https://books.toscrape.com/> — демо-магазин для парсинга, открыт без авторизации. Парсятся страницы каталога `catalogue/page-1…5.html` (ровно 100 обложек). Адрес задан в [app/config.py](app/config.py).

**Концепция:** «улучшение карточек товаров» + творческие стили (комикс, ретро, пиксель-арт, набросок).

## Запуск

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt      # CPU-torch: --extra-index-url https://download.pytorch.org/whl/cpu
uvicorn app.main:app --reload
```
Откройте http://127.0.0.1:8000. Тесты: `python -m pytest`.

## Цепочка
интерфейс (`static/`) → `POST /api/analyze` (FastAPI) → `parser.py` (HTML с тайм-аутом, `<img>`, относительные ссылки → абсолютные, загрузка с лимитом размера) → `processing.py` (статистика NumPy, фильтры NumPy/PyTorch) → JSON с оригиналами и результатами (data URI) → галерея «до/после».

## API
| Метод | Маршрут | Назначение |
|---|---|---|
| GET | `/health` | готовность |
| GET | `/` | интерфейс |
| GET | `/api/filters` | список фильтров и пресетов |
| POST | `/api/analyze` | `{filter, intensity 0..1, limit 1..20}` → источник, сводка, изображения со статистикой, применённые фильтры, список ошибок |

Устойчивость: тайм-ауты на страницы и картинки (10 с), лимит 3 МБ на файл, ≤20 изображений, превью ≤320 px. Недоступное или битое изображение попадает в `errors`, остальные обрабатываются.

## Статистика (NumPy)
Ширина, высота, соотношение сторон, средняя яркость, контраст (std яркости), средний цвет, доли тёмных/светлых пикселей, 16-бинная гистограмма, флаги («слишком тёмное», «низкий контраст»).

## Фильтры
**NumPy (операции над массивами):** `grayscale`, `invert`, `sepia`, `posterize`, `pixelate`, `threshold`, `gamma` (подъём теней), `auto_contrast` (растяжение гистограммы).
**PyTorch (`torch.nn.functional.conv2d`, тензор 1×C×H×W, depthwise):** `blur`, `sharpen`, `emboss`, `edges` (Собель, чёрные линии на белом), `ink` (контуры Собеля поверх картинки).

**Пресеты:**
- `product_boost` — автоконтраст + гамма + резкость: ярче и чётче карточка товара.
- `comic` — постеризация + чёрные контуры: плоские цвета с обводкой.
- `retro` — сепия + лёгкое размытие + тиснение: выцветшая плёнка.
- `pixel_art` — крупные пиксели и ограниченная палитра.
- `sketch` — только контуры, карандашный набросок.

Интенсивность 0..1 масштабирует силу каждого шага цепочки.
